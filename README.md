# Week 6 Assignment: SQL Joins and Relationships

## Introduction
This assignment focuses on understanding and implementing SQL joins to retrieve related information from multiple database tables using the MySQL Classic Models database.

## Learning Objectives
- Understand INNER JOIN, LEFT JOIN, and RIGHT JOIN.
- Retrieve data from related tables.
- Understand relationships between database tables.
- Apply SQL joins to solve real-world database problems.

## Assignment Questions

### Question 1: INNER JOIN – Employees and Offices
Retrieves employee first names, last names, email addresses, and office codes by joining the employees and offices tables.

### Question 2: LEFT JOIN – Products and Product Lines
Retrieves product names, product vendors, and product lines using a LEFT JOIN.

### Question 3: RIGHT JOIN – Customers and Orders
Retrieves the order date, shipped date, status, and customer number for the first 10 orders using a RIGHT JOIN.
